# Repository Contents

This repository contains the R scripts and spatial datasets used for the Red Deer distribution modelling study in South Tyrol.

## Scripts

- **`Thesis_Script_new.R`** – Main analysis script, including data processing, model building, and model evaluation.
- **`Plots_Tables.R`** – Script for generating the figures and tables presented in the study.

## Spatial Data

- **`Jagdreviere_nach_1983.shp`** – Shapefile containing the hunting district boundaries of South Tyrol.

## Red Deer Count Data

The following datasets were provided by the Office for Wildlife Management of the Autonomous Province of Bolzano – South Tyrol (Amt für Wildtiermanagement der Autonomen Provinz Bozen – Südtirol):

- **[`Populationseinheiten Rotwild.shp`](https://github.com/radlfahrer/RedDeer_SDM_SouthTyrol/blob/main/Populationseinheiten%20Rotwild.shp)** – Spatial boundaries of the red deer population units.
- **[`Rotwildzaehlungen 2015-2025.xlsx`](https://github.com/radlfahrer/RedDeer_SDM_SouthTyrol/blob/main/Rotwildzaehlungen%202015-2025.xlsx)** – Raw red deer count data for the period 2015–2025.
- **[`count_data_processed.gpkg`](https://github.com/radlfahrer/RedDeer_SDM_SouthTyrol/blob/main/count_data_processed.gpkg)** – Processed red deer count data used for model evaluation in this study.

The count data may no longer reflect the current situation. Any further use of these data requires the approval of the Office for Wildlife Management.
